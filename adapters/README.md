# アダプター

このディレクトリは任意の同梱例。削除・交換しても通常のverifyは動く。
登録は`npm run verify:registration`、比較実験は`npm run verify:examples`で明示的に検証する。

外部ワークフローとプロジェクトの完了契約を接続する機械可読な宣言を置く。
アダプターは外部SKILLの内容を複製せず、次だけを記録する。

- 外部リポジトリと固定コミット
- ワークフローを構成する工程
- パス、形式、ライフサイクルの変換
- 必要な権限
- 正常系、失敗系、敵対的ケースの認証結果

認証は外部SKILLの出力品質や完全な安全性を保証しない。外部SKILLを更新する場合は、
安定版を維持したまま更新候補で契約テストを実行する。

`candidate`は接続定義があるだけで、認証済みではない。正常系、失敗系、敵対的ケースの
実地検証がすべて完了した場合だけ`certified`へ変更する。
