# 用語集

## 外部ワークフロー

調査、仕様化、計画、実装、レビューなどの知的な開発手順を提供する、交換可能な
SKILLまたはエージェントの組み合わせ。

## 完了契約

外部ワークフローに依存せず、成果物、受け入れ条件、検証証跡、承認、アーカイブに
対してプロジェクトが強制する不変条件。
変更マニフェストとリスク分類を含み、外部SKILLの登録・認証・比較実験は含まない。

## アダプター

外部ワークフローの入出力を完了契約へ接続する薄い変換層。意味的な判断は行わない。

## 認証済み

指定した外部ワークフローのバージョンについて、接続、成果物変換、停止条件、
完了契約への適合を契約テストで確認済みであること。出力品質や安全性の保証ではない。
任意の登録検証で確認するもので、通常のverifyの成功とは区別する。

## 承認対象コミット

検証、独立レビュー、文書整理を済ませたGitコミット。高リスク変更では人間がこのSHAを承認する。
承認後は未追跡の一時マニフェストだけを更新でき、それ以外の変更は再承認が必要。

## 変更分類

**軽微変更**:
動作や仕様の意味を変えない誤字・コメント・整形の修正。リファクタリング、不具合修正、
高リスク変更は含まず、変更行数の少なさや低リスクであることだけでは該当しない。
_Avoid_: 小さい差分、低リスク変更との同一視

**通常扱い**:
軽微変更として確認されていない変更に適用する、チケットを必要とする文書手続き。
リスク分類とは別であり、高リスク変更も含む。
