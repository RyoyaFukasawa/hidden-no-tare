# 01: SKILLに依存しない完了契約を提供する

## 実現する振る舞い

利用例を削除・交換しても文書と完了契約が使え、不正な入力や承認対象外の変更で完了しない。

## 依存チケット

なし（すぐに着手可能）。

## 受け入れ条件

- [ ] ワークフロー情報なしで開始・検証でき、利用例を取り除いても必須機能が動く。
- [ ] 設定・マニフェストの欠落や型不正と、完了時の未分類を拒否する。
- [ ] 承認後のstaged・unstaged・untracked変更を拒否し、一時マニフェストだけ更新できる。
- [ ] 検証が変更を作った場合はfinalizeせずマニフェストを保持する。
- [ ] 診断の対象範囲と限界、外部ツールの導入方法と不足時の案内がある。
- [ ] 現行仕様・新ADR・指示を更新し、独立レビューと文書整理後にverifyが成功する。

## 検証結果

開始前の基準: main a244af6、npm test 54件成功。
最終コミットに対する人間承認はこの実装チケットとは別に一時マニフェストで扱う。
