# ADR-0003: 軽微変更は一時マニフェストを維持しチケットを省略する

## 背景

開発手順を外部SKILLへ委ね、成果物と完了条件をプロジェクトの契約として維持する。
ただし意味を変えない誤字・コメント・整形にもチケットの作成・保管を要求すると負担が大きい。
一時マニフェストまで省略する案も検討したが、状態と分類の管理を失う必要はないと判断した。

## 決定と理由

### 継続する責務と任意機能

外部SKILLとエージェントは全体・フェーズ・個別単位で交換する。
プロジェクトは長期成果物、形式、受け入れ条件、証跡、分類、レビュー、保存契約を所有し、
決定論的なCLIで検証する。意味的な判断は外部フロー、接続は薄いアダプターが担う。
変換できない情報は創作せず差し戻す。

変更マニフェスト・リスク分類・高リスク変更の人間承認は必須とする。
外部ワークフローの登録、固定バージョン記録、認証、比較実験は任意とし、削除・交換しても
通常のverifyや文書契約が動くことを要求する。利用する外部SKILLの出所・ライセンス・
固定版・権限・危険命令の確認は継続する。認証は指定版との境界適合性であり、品質・安全性の保証ではない。

### 軽微変更の文書手続き

軽微変更だけチケットとそのアーカイブを省略する。一時マニフェストを全変更で維持し、
軽微変更の区分、分類理由、検証結果、レビューを記録する。代替の長期文書は要求しない。

対象は動作や仕様の意味を変えない誤字・コメント・整形に限定する。
リファクタリング、不具合修正、高リスク変更は対象外。行数や低リスク判定だけでは省略できない。
エージェントが理由を記録し、独立レビューで差分と分類を確認する。
不確実な場合は通常扱いに戻す。意味の同一性は機械だけで判定しない。
軽微変更であると確認されない変更には、従来どおりチケットと必要成果物を要求する。

### 継続する検証・承認と導入方針

検証・独立レビュー・必要な文書整理後にコミットし、高リスク変更はそのコミットを人間が承認する。
完了時にはHEADの一致に加え、通常のGit ignore対象と検証済み未追跡一時マニフェスト以外の
未コミット変更を拒否する。並行作業は別worktreeを使い、承認後の追加変更には再承認を要求する。
軽微変更でもverify、検証中の変更検出、finalizeの成功条件を緩めない。

新規リポジトリへの導入を主対象にする。既存向け診断は限定した比較であり安全な移行を保証しない。
既存ファイルは承認なく上書きしない。外部ツールを許容し、必要版・導入方法・不足時の案内を提供する。

## 影響

軽微変更の分類理由・検証結果は一時マニフェストで扱い、完了後は長期保存しない。
通常扱いのチケットとアーカイブ、およびアーカイブ内の仕様・計画の分割をSKILLに任せる方針は継続する。
設定とマニフェストの型不正・欠落を実行時に拒否し、一時マニフェストをGit追跡しない方針も維持する。
分類の誤りは独立レビューで検出する必要があり、機械検証の成功だけでは分類の妥当性を保証できない。

CLI・現行仕様・エージェント向け指示は同じ変更単位で切り替える。
適用内容と検証証跡は[実装チケット](../archive/2026-09-15-lightweight-changes/issues/01-lightweight-changes.md)に記録する。
