# ADR-0001: 外部ワークフローと完了契約を分離する

## 背景

開発SKILLは継続的に改善され、優れた手順や構成も入れ替わる。プロジェクトが
特定SKILLの手順や成果物形式へ密結合すると、乗り換えのたびに運用と履歴が変わる。
一方、既存SKILLと競合する独自SKILLの開発と保守は目的ではない。

## 決定と理由

外部SKILLやエージェントを交換可能なワークフロー実装として扱い、長期成果物と
完了条件をプロジェクト所有の契約として分離する。状態と検証は決定論的なCLI、
意味的な作業は外部ワークフロー、両者の接続は薄いアダプターが担う。

この分離により、外部SKILLを改造せず更新や交換ができ、同時に未検証の作業や
未確認事項が完了として扱われることを防げる。

## 影響

アダプターは外部成果物と標準成果物の差を管理する必要がある。情報を損失なく
変換できない場合は自動補完せず、完了を止める。認証済みという表現は境界の
適合性だけを示し、外部SKILLの出力品質や完全な安全性を保証しない。

契約と外部ワークフローは固定バージョンを使用し、診断と明示承認を経て更新する。
