# 02: SKILL非依存の完了契約を実装する

## 実現する振る舞い

開発者が外部SKILLやエージェントを交換しても、成果物、検証証跡、リスク承認、
緊急例外、完了判定を同じプロジェクト契約で管理できる。

## 依存チケット

01: ルート移動後の検証パスを修復する

## 受け入れ条件

- [x] 未分類の変更は調査と試作以外へ進めない
- [x] 変更特性から必要な標準成果物を導出する
- [x] 通常変更と高リスク変更で必要なレビューを分ける
- [x] 検証失敗、未実行、証跡不足を完了として扱わない
- [x] 緊急例外の既定7日、最大30日を強制する
- [x] 外部SKILLの固定出所、権限、変換、認証テストを宣言できる
- [x] 危険な命令と秘密情報らしき値を検出する
- [x] 契約検証とプロジェクト固有検証を分離して統合実行する
- [x] 既存プロジェクトの衝突を変更せず診断する

## 検証結果

- `npm run verify`で契約、型検査、単体テスト、ADR、Markdown、リンクが成功した。
- `npm audit`で依存関係の脆弱性が0件であることを確認した。
- 正常系、失敗系、高リスク、期限切れ、敵対的SKILLを含むテストが成功した。
